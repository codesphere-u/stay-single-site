# Stay Single — brand site

The website for **Stay Single** ([@stay_single_men](https://www.tiktok.com/@stay_single_men) on TikTok):
a brand home page, a link-in-bio hub, and a branded 404. Zero dependencies — plain HTML, CSS and
JavaScript generated by Node.

## Run it

```bash
npm start
```

Then open http://127.0.0.1:4180 (the link hub is at `/links.html`).

```bash
npm test
```

```bash
npm run build
```

`npm run build` writes the static site to `dist/`, ready for any static host.

## Edit the content

Everything the site says lives in [`src/data/brand.mjs`](src/data/brand.mjs):

| What | Field |
| --- | --- |
| Tagline and intro | `line`, `intro` |
| Words on the moving band | `themes` |
| The scroll-lit manifesto (and which words glow ember) | `manifesto`, `manifestoKeys` |
| The three pillars | `pillars` |
| Instagram, YouTube, X, Threads… | `socials` — fill in `url`; empty ones are hidden everywhere |
| Specific TikToks to feature | `featuredVideos` — full video URLs |
| Newsletter / community sign-up | `newsletter.action` — your provider's form URL; until then the site shows "The list opens soon" |

Restart `npm start` after editing so the pages regenerate.

## How the TikTok videos load

The **Watch** section uses TikTok's official Creator Profile Embed (follower counts and recent videos).
Nothing from TikTok — script or cookies — loads until a visitor presses **Load videos from TikTok**.

## Deploy

On Vercel, import the repository; `vercel.json` runs `npm run build` and serves `dist/`
(with `/links` mapped to the link hub). Put `https://your-domain/links` in the TikTok bio.
